# Task14-Basic-Sales-Summary

Project Overview

This project uses Microsoft Excel to create a basic sales summary and calculate important business metrics.

Objectives

- Calculate total sales.
- Calculate average sales.
- Count sales transactions.
- Create a simple summary sheet using Excel formulas.

Tools Used

- Microsoft Excel
- SUM, AVERAGE, and COUNTA formulas

Deliverables

- Excel workbook containing the sales data and Summary sheet.
- Three KPIs: Total Sales, Average Sales, and Transaction Count.

Outcome

Completed a basic sales analysis to understand overall sales performance using Excel formulas.
